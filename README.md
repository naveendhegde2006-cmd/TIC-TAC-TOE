# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe game** built using HTML, CSS, and JavaScript. Two players take turns marking spaces on a 3×3 grid. The first player to get three marks in a row wins!

## 🚀 Features

- 🎯 Two-player gameplay (O and X)
- 🏆 Automatic winner detection
- 🤝 Draw detection when all nine boxes are filled
- 🔄 New Game button to start another round
- ♻️ Reset Game button to clear the board
- 🔒 Disables boxes after a winner or draw
- 🎨 Simple and attractive user interface
- 📱 Responsive layout using CSS viewport units

## 🛠️ Technologies Used

- **HTML5** — Structure of the game
- **CSS3** — Styling and layout
- **JavaScript** — Game logic, event handling, and winner detection

## 🎮 How to Play

1. Open the game in your browser.
2. Player O starts the game.
3. Players take turns clicking an empty box.
4. The first player to match three marks horizontally, vertically, or diagonally wins.
5. If all nine boxes are filled without a winner, the game ends in a draw.
6. Click **New Game** or **Reset Game** to play again.

## ⚙️ How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/tic-tac-toe.git
   ```

2. Open the project folder:

   ```bash
   cd tic-tac-toe
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code.
